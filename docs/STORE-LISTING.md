## 一句话简介

现场拍照自动加水印：斜压 GSZD 大字 + 时间、经纬度、地址，一拍就有，离线也能用。

## 功能介绍（按真实功能写，不夸大）

- **拍照打水印**：打开就能拍，一次一张；3:4 取景，顶部项目名称 + 四个控制按钮，快门在模式药丸下方居中；水印真烧进照片像素：斜压大字（默认 GSZD，可改成其他文字，透明度可在设置页滑块调）+ 底部信息条（项目名称、时间、经纬度度分秒、地址）。
- **视频也打水印**：同一版式，1080p，时长不限，拍完能预览、能删。
- **项目名称**：拍摄界面点顶部项目名称（或“更多”）输入，记住上次输入的，支持历史快速选。
- **定位与地址**：GPS 定位转 GCJ-02，联网查地址（高德地址服务已内置，拿不到时用 OpenStreetMap）；没网时地址留空，绝不编造。
- **相册管理**：顶部搜索（按项目名称、地址、日期过滤）、按日期分组、文件夹归档、长按多选批量删除、单张分享导出；详情页左右滑动切换上一张/下一张。
- **自更新**：启动时自动检查新版本，有更新可直接在 App 内下载安装（首次需在设置里允许一次“安装未知应用”）。
- **对焦曝光**：点取景器对焦、上下滑调曝光、双指缩放、长按变焦按钮滑动变焦。
- **离线可用**：没网也能拍、能存；有网后地址自动补上。
- **隐私**：不注册、不登录、不收集账号；没有广告，没有第三方统计；照片、视频只保存在本机和系统相册。
